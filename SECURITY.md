# Sicherheitsrichtlinie

## Schwachstellen melden

Bitte **keine öffentlichen Issues** für Sicherheitsprobleme. Melde sie über
**GitHub → Security → „Report a vulnerability“** (Private Vulnerability Reporting).
Wir antworten innerhalb von 7 Tagen.

## Unterstützte Versionen

Unterstützt wird nur die jeweils neueste Version von App und Server. Ältere Apps werden über die vom Server erzwungene Mindestversion aktualisiert.
